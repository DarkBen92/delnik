# Дельник

Недельный планировщик задач на русском языке: неделя как в бумажном ежедневнике, списки «Когда-нибудь»,
повторы, напоминания, несколько календарей, темы и печать. Все функции бесплатны.

Работает в браузере и устанавливается как приложение (PWA). Данные хранятся на вашем устройстве.

## Возможности

- Неделя как разлинованный лист: шесть колонок, суббота и воскресенье вместе; неделя начинается с понедельника.
- Лента месяцев сбоку: видно задачи на месяцы вперёд, клик по неделе открывает её.
- Задачи с цветом, заметкой, подзадачами, временем, вложениями; перетаскивание между днями, неделями (через стрелки) и списками.
- Повторы: каждый день, по дням недели, каждые N дней/недель/месяцев/лет, до даты.
- Напоминания через уведомления браузера.
- Несколько календарей, ссылка-копия календаря, резервная копия JSON.
- Экспорт и импорт `.ics` (Google, Apple, Outlook).
- Светлая, тёмная и своя тема; стикеры на днях; печать заполненной или пустой недели.
- Поиск по задачам.

### Особенности Дельника

- **Оранжевый акцент** и тёмная тема с почти чёрным фоном.
- **Строка быстрого ввода над неделей** (на телефоне — внизу экрана): пишешь по-русски — «завтра в 18:00 позвонить маме»,
  «каждую среду бассейн», «по будням стендап в 10:00 !синий» — и сразу видишь, как Дельник понял дату, время и цвет.
- **Производственный календарь РФ:** праздники, переносы и сокращённые дни.
- **Перенос «хвостов»:** плашка «N хвостов с прошлых дней» с кнопкой «Перенести на сегодня»; можно включить автоперенос.
- **Прогресс на виду:** счётчик «сделано/всего» у каждого дня и полоска прогресса недели в шапке.
- **Телефон:** лента дней недели сверху, свайп листает недели, ввод задачи под большим пальцем.
- **Итоги недели:** сколько сделано, по дням, серия дней без хвостов.
- **Фокус-таймер** 25/5 прямо из задачи.
- **Горячие клавиши:** ←/→ неделя, T сегодня, N быстрый ввод, M месяц, / поиск, ? справка.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты (Vitest)
npm run build      # проверка типов и сборка в dist/
```

Стек: React 19, TypeScript, Vite, Zustand, dnd-kit. Доменная логика — чистые функции в `src/domain`,
интерфейс — `src/ui`, хранилище — `src/store`.

## Публикация на Cloudflare

Дельник — статический сайт, серверный код не нужен. Настройки лежат в `wrangler.jsonc`:
сборка `npm run build` кладёт сайт в `dist/`, а `npx wrangler deploy` публикует его в Cloudflare Workers.

Один раз в панели Cloudflare: **Workers & Pages → Create → Import a repository**, выбрать этот репозиторий,
команда сборки `npm run build`, команда публикации `npx wrangler deploy`. После этого каждый пуш в `main`
выкладывается сам. Свой домен подключается в настройках воркера: **Settings → Domains & Routes → Add → Custom domain**.
