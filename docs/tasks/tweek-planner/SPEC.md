# Спецификация: tweek-planner

## Цель
Пользователь открывает «Дельник» в браузере или как установленное PWA и планирует неделю:
задачи по дням, списки «Когда-нибудь», повторы, напоминания, несколько календарей, темы — всё бесплатно и по-русски.

## В scope
Всё из BRIEF «Функции Tweek» в пределах допущений + изюминки (AC-17…AC-22).

## Вне scope
Сервер, аккаунты, двусторонняя синхронизация, совместное редактирование в реальном времени, email, нативные виджеты.

## Контракты
- Данные: `src/domain/types.ts` (`AppData` со `schemaVersion`), хранение в localStorage под ключом `delnik:data:v1`.
- Вложения: IndexedDB `delnik-files`, метаданные в задаче.
- Даты: строки `YYYY-MM-DD` в локальном времени; день недели ISO (1 = Пн … 7 = Вс).
- Резервная копия: JSON `{ app: "delnik", schemaVersion, data }`; ссылка-снимок: `#share=<base64url(JSON)>`.
- ICS: RFC 5545 VEVENT (весь день или с временем), RRULE для повторов.

## Критерии приёмки
- AC-01: Недельный вид: 7 колонок Пн–Вс с русскими названиями и датами, сегодняшний день выделен; кнопки «предыдущая/следующая неделя» и «Сегодня».
- AC-02: Виды «День» и «Месяц» (сетка 6×7 с понедельника); переход в день по клику.
- AC-03: Добавление задачи в день и в список «Когда-нибудь», редактирование, удаление.
- AC-04: Отметка выполнения (зачёркивание), настройка «скрывать выполненные».
- AC-05: Перетаскивание задач между днями, неделями (на стрелки навигации) и списками, порядок внутри дня; перенос через выбор даты в редакторе.
- AC-06: Задача: заметка, цвет (8 вариантов), подзадачи с отметкой, время, вложения файлов.
- AC-07: Повторы: ежедневно, по дням недели, каждые N дней/недель/месяцев/лет, до даты; выполнение отдельного вхождения; удаление одного вхождения или всей серии.
- AC-08: Напоминания: уведомление браузера за N минут до времени задачи (запрос разрешения).
- AC-09: Несколько календарей с переключением; у каждого свои задачи и списки.
- AC-10: Поделиться календарём ссылкой-снимком; экспорт/импорт резервной копии JSON.
- AC-11: Экспорт календаря в .ics и импорт .ics (Google/Apple/Outlook).
- AC-12: Темы: светлая/тёмная/системная + собственные цвета; стикеры-эмодзи на днях.
- AC-13: Печать недели: заполненная и пустая.
- AC-14: Поиск по задачам всех дат и списков.
- AC-15: PWA: manifest, иконка, service worker для офлайна.
- AC-16: Данные сохраняются между перезагрузками.
### Изюминки
- AC-17: Быстрый ввод по-русски: «завтра в 18:00 позвонить маме», «каждый понедельник планёрка», «в пятницу !красный» → дата, время, повтор, цвет.
- AC-18: Производственный календарь РФ: праздники и сокращённые дни подсвечены (2025–2026 по постановлениям, иные годы — фиксированные праздники).
- AC-19: Перенос «хвостов»: невыполненные задачи прошлых дней переносятся на сегодня автоматически (настройка) или по кнопке.
- AC-20: Итоги недели: выполнено/всего, по дням, серия дней без хвостов.
- AC-21: Фокус-таймер (25/5) из задачи.
- AC-22: Горячие клавиши: ←/→ недели, T — сегодня, / — поиск, ? — справка.

## Риски
- Уведомления в фоне без сервера ограничены браузером: работают, пока вкладка/PWA активны.
- Данные производственного календаря 2025 — по памяти, 2026 — по Skillbox; проверить по постановлению.
