# tweek-planner: Дельник — недельный планировщик

## Исходный запрос
> Отлично, теперь задача такая, создай пожалуйста аналог https://tweek.so/ru, только со всеми плюшками, что и в платной версии
> Изучи полностью этот проект и скопируй его для удобного использования с бесплатной премиум версией. Добавь свои изюминку, чтобы были отличия от оригинала. Сделать пожалуйста орентир на русского язычную аудиторию
> Но важно, функционал весь аналогичен tweek.so

## Расширенный запрос
Собственный продукт «Дельник» с функциональностью Tweek (бесплатный и платный тариф), где всё премиальное бесплатно.
Код, название, логотип, иллюстрации и тексты Tweek не копируются: повторяются только функции и UX-паттерны.
Интерфейс на русском, неделя с понедельника, российские форматы дат. Плюс собственные отличия.

## Функции Tweek (исследование)
Источники: страница в App Store, TrustRadius (сайт tweek.so рендерится только JS).
- Бесплатно: недельный вид «как бумажный ежедневник» без почасовой сетки, вид дня, месяца;
  списки «Когда-нибудь»; задачи, заметки, чек-листы/подзадачи, цвета задач; перетаскивание между днями и неделями;
  тёмная тема; веб + мобильные.
- Premium: повторяющиеся задачи (дни недели, интервалы), напоминания (push/email), несколько календарей,
  совместный доступ к календарю и задачам, синхронизация с Google/Apple/Outlook календарями, вложения файлов,
  собственные цветовые темы, стикеры, печатные шаблоны недели (заполненные и пустые), виджеты.

## Допущения (выбраны по умолчанию, сообщены пользователю)
- Адаптивное веб-приложение + PWA (устанавливается на телефон/ПК), стек Vite + React + TypeScript — репозиторий был пуст.
- Без сервера: данные хранятся локально (localStorage, вложения — IndexedDB). Поэтому:
  - совместный доступ = ссылка-снимок календаря + файл резервной копии, а не совместное редактирование в реальном времени;
  - синхронизация с Google/Apple/Outlook = экспорт/импорт .ics, а не двусторонняя синхронизация (нужен OAuth и бэкенд);
  - напоминания = уведомления браузера, пока приложение открыто/установлено; email-напоминаний нет.
- Все премиум-функции бесплатны, нет пейволла.
- Виджеты ОС нативных приложений вне scope (веб-приложение).
